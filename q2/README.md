# AT3 — Questão 2: tabela de declarações (Flex e Bison)

Analisa declarações com int, double e char, separadas por ponto e vírgula. Cada variável é listada apenas na primeira declaração; nomes repetidos produzem a mensagem de erro. Ao final, mostra a quantidade de nomes distintos registrados.

## Como executar

make
./decl entrada.txt

Também pode receber texto da entrada padrão: ./decl.

## Testes

make test
make clean

Arquivos obrigatórios da entrega: decl.l, decl.y e Makefile.
